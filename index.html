1. Быстрый старт

Одна задача: открыть агента, написать, что нужно, ответить на вопросы, получить проверенный результат и сумму затрат.

  1. Откройте ярлык «1С-архитектор» на рабочем столе.
    Если ярлыка нет — создайте один раз: 
    powershell -NoProfile -ExecutionPolicy Bypass -File C:\Users\awd22\.config\opencode\scripts\create-shortcut.ps1
  2. Введите путь к папке проекта.
    Например: D:\Работа\осьминог\ООО СЕМАКС МЕТАЛЛ
    Кавычки-«ёлочки» и обычные кавычки скрипт срезает сам. Путь запоминается — второй раз не спросит.
  3. Дождитесь сообщения «Готово». Первый запуск сам создаёт рабочую папку project/ внутри проекта.
  4. В окне OpenCode нажмите Tab и выберите 1c-architect, затем Enter.
  5. Напишите задачу простыми словами. Например: 
    В проекте лежит ТЗ. Сначала проведи аудит того, что уже сделано,
потом задай вопросы и покажи план с оценкой.
  6. Ответьте на вопросы и напишите «делай». До этого он ничего не меняет — это специально.
  7. Получите таблицу приёмки, затраты в рублях и путь к результату.
Если модель молчит — нет ключа. Откройте C:\Users\awd22\.config\opencode\.env, впишите после ROUTERAI_API_KEY= свой ключ с routerai.ru, перезапустите ярлык.

3. Как он работает

Порядок жёсткий, обойти нельзя:

1. Аудит
Субагент 1c-scout смотрит, что уже есть в проекте и базе. Проект мог бросить другой ИИ — ничего рабочего не сносится без доказательства.
2. Вопросы и план
Что понял, до 5 вопросов с вариантом по умолчанию, план с рисками и оценкой. И стоп — ждёт вашего «делай».
3. Работа
1c-coder пишет XML и BSL, 1c-tester собирает расширение и прокликивает сценарий в живом окне 1С.
4. Приёмка по галочкам
Галочка ставится только при наличии артефакта: лог, код возврата, путь к скриншоту, цифра. Нет артефакта — ❌.

4. Что он спросит

Пример ответа агента:

Что понял: нужна доработка закрытия месяца с расчётом резерва.

Вопросы:
1) Резерв считаем по всем договорам или только по просроченным?
   рекомендую: по всем, с признаком просрочки в отчёте.
2) Префикс объектов: оставить АС_ или свой?
3) Куда выводить результат: отчёт СКД или заполнение документа?

Предложение:
- регистр сведений «Резервы» + подписка на проведение;
- отчёт СКД;
риски: если в ТЗ нет формулы, цифры не сойдутся — нужна ваша формула;
оценка: 3 шага, ~15–25 ₽.

Отвечайте как в переписке: 1 — по всем, 2 — АС_, 3 — отчёт, делай.

Не хотите разбираться: бери рекомендации по умолчанию и делай.

6. Как проверить, что не соврал

  • Спросите «покажи лог сборки». Нужен путь к логу и код возврата 0. Нет — не собирал.
  • Спросите «покажи скриншоты» и откройте project/qa/<дата>/ сами. Пусто — не проверял.
  • Откройте project/journal.md. Агент говорит «работал», а журнал пустой — работа наполовину.
  • Говорит «сделано», а в git diff нет файлов — не сделано.
Честный ответ «не проверено, причина такая» — нормальный. Ответ «всё работает» без артефактов — повод перепроверить.

9. Границы и безопасность

Где работает

Проект — это норма. Наружу (поиск, документация, чужие репозитории) — только когда в проекте этих данных нет.

Что не уходит наружу

Код клиента, фрагменты выгрузки, контрагенты, цифры, пароли, ключи. Запросы формулируются обобщённо.

Секреты

Только в .env. В коде, логах, project/ и коммитах — никогда.

Необратимое

Рабочая база, git push, reset --hard, удаление кода — только с вашего «да».

10. Другой компьютер

  1. Установить OpenCode: npm install -g opencode-ai
  2. Скачать репозиторий 1c-agent-opencode (Code → Download ZIP).
  3. Скопировать prompts, skills, templates, scripts в C:\Users\<имя>\.config\opencode\ поверх.
  4. Вставить секции провайдера и агентов из opencode.example.json в свой opencode.json.
  5. Вписать ROUTERAI_API_KEY в .env.
  6. Создать ярлык: scripts\create-shortcut.ps1. Перезапустить OpenCode.

11. Если сломалось

Агента нет в Tab
Перезапустите OpenCode. Проверьте: opencode debug agents — должно быть четыре 1c-*.
Ошибка кодировки в скрипте (кракозябры, «отсутствует завершающий символ»)
Скрипт сохранён без BOM или повреждён. Возьмите свежий из репозитория и запускайте так: powershell -NoProfile -ExecutionPolicy Bypass -File <путь>.
Модель не отвечает
Пустой ROUTERAI_API_KEY или нет баланса на routerai.ru.
Слишком дорого
Скажите: «ответы по умолчанию, дальше сам» — он перестанет водить вас по вопросам. Субагенты на DeepSeek стоят копейки, дорогой только архитектор на Sonnet.
Полез в рабочую базу
Остановите: «не трогай рабочую, только тестовая». В project/context.md укажите тестовую базу — он читает её перед работой.
Завис на синтаксисе
Напишите: «покажи, что уже успел, и остановись». Затем дайте текст ошибки и лог.
Хочу другой проект
Удалите C:\Users\awd22\.config\opencode\scripts\.1c-agent-state.json или запустите скрипт с -ProjectPath "D:\другой".
