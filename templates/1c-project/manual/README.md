# Пакеты ручного внесения

Сюда складываются изменения, которые агент **не может** внести сам и передаёт человеку: объекты на поддержке, бинарные формы, конфликт захвата в хранилище, доступ только через Конфигуратор.

Формат пакета: `manual/<YYYY-MM-DD>-<краткое-имя>.md`

```
# Пакет: <название>

Конфигурация / расширение:
Объекты:
  - <тип> <имя> -> <что сделать>

## Найти / Заменить целиком

### 1. <объект>, модуль <какой>
Найти:
    <строка или блок>

Заменить целиком на:
    <блок>

## Таблица реквизитов / элементов формы (если добавляем)

| Объект | Реквизит | Тип | Значение по умолчанию | Примечание |
|---|---|---|---|---|

## Проверка после внесения

1. Конфигурация -> Проверить синтаксис, ошибок нет
2. Обновить конфигурацию БД
3. Открыть форму <какая>, проверить <что>

## Откат

- Вернуть исходный код: <что именно>
- Версия/резервная копия до изменений: `dumps/<файл>`
```

Правила:

- один пакет - одна задача, чтобы откат был понятным;
- блоки «Найти» - ровно из текущего файла, без пересказа по памяти;
- после того как человек внёс, он ставит галочку и дату внизу пакета, агент проверяет сборкой и пишет запись в `journal.md`.
