# Журнал работы

Формат записи (одна запись = одна порция работы, даже неудачная):

```
## YYYY-MM-DD HH:MM - <короткое название>
Задача: <пункт ТЗ или свободная формулировка>
Делал: агент 1c-architect / 1c-coder / 1c-tester / человек
Что сделано: <файлы, объекты, строки>
Артефакты: <путь к логу, скриншоту в qa/, код возврата, фактическая цифра>
Статус: сделано / в работе / заблокировано
Следующий шаг: <если не сделано>
```

Правила:

- дописывать вниз, прошлое не стирать;
- без артефакта - не «сделано»;
- ошибочную запись не удалять, а рядом писать опровержение с датой.
