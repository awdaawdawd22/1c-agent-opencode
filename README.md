# 1С-архитектор для OpenCode

Автономный оркестратор разработки 1С:Предприятие 8.3 под OpenCode: один главный агент и три субагента, с аудитом сделанного, вопросами до работы, приёмкой по артефактам, учётом затрат в рублях и рабочей папкой проекта.

Собрано и проверено на живом OpenCode (8.3.27.1989, Windows x64).

---

## Что внутри

| Агент | Модель | Что делает |
|---|---|---|
| `1c-architect` | Claude Sonnet 5.5 (ч/з RouterAI) | Главный: аудит, вопросы и план с оценкой, распределение работы, приёмка по галочкам, отчёт с затратами |
| `1c-scout` | DeepSeek V4.1 Flash | Аудит проекта, поиск по выгрузке, установка недостающих MCP и навыков |
| `1c-coder` | DeepSeek V4.1 Flash | XML метаданных, формы, роли, макеты, BSL-рутина |
| `1c-tester` | DeepSeek V4.1 Flash | Сборка через `1cv8.exe DESIGNER`, окна 1С, скриншоты, сверка цифр |

Как это работает со стороны человека - `1C-АГЕНТ-ИНСТРУКЦИЯ.md` (пошагово, без программирования).

---

## Что умеет

- **Аудит вместо переписывания с нуля.** Первым делом проверяет, что уже сделано (в т.ч. если проект начинал другой ИИ), и продолжает с места остановки.
- **Вопросы до старта.** Что понял, до 5 вопросов с вариантом по умолчанию, план с рисками, оценка в шагах и рублях, потом «ждёт подтверждения».
- **Границы.** Работа - в папке проекта. Наружу (поиск, документация, чужие репозитории) - только когда в проекте этих данных нет. Данные проекта наружу не уходят.
- **Безопасность.** Секреты в `.env`, чужие репозитории в карантине с проверкой, никаких `curl | sh`, никаких публичных действий от вашего имени.
- **Приёмка только с доказательством.** Лог сборки с кодом `0`, `/CheckConfig` без ошибок, скриншот из `project/qa/<дата>/`, фактическая цифра.
- **Учёт затрат.** `scripts/cost-report.cjs` считает токены и рубли по ценам RouterAI.
- **Рабочая папка проекта.** `project/` с контекстом, правилами, журналом, решениями, рисками, чек-листами.
- **Каталог инструментов.** `skills/1c-mcp-catalog.md`: проверенные MCP для 1С (gyrfalcon, bsl-context, 1c-mcp-toolkit, code-index-mcp, 1C Testpilot и др.), порядок установки.

## Установка на новом ПК

Нужно: Windows 10/11 x64, OpenCode (Node 22+), 1С:Предприятие 8.3 в `C:\Program Files\1cv8\8.3.x\bin`, ключ RouterAI.

1. Установить OpenCode: `npm install -g opencode-ai` (или по инструкции с opencode.ai).
2. Скачать этот репозиторий (кнопка **Code → Download ZIP**) и распаковать.
3. Скопировать содержимое в папку конфига OpenCode `C:\Users\<имя>\.config\opencode\`:
   - скопировать папки `prompts`, `skills`, `templates`, `scripts` **поверх** (существующие файлы не удалять);
   - `opencode.json` не перезаписывать целиком - вставить секции из `opencode.example.json` (см. ниже).
4. Создать `.env` в `C:\Users\<имя>\.config\opencode\`:
   ```
   ROUTERAI_API_KEY=свой_ключ_с_routerai.ru
   ```
5. Перезапустить OpenCode. Проверить, что агенты и модели на месте:
   ```powershell
   opencode models | Select-String routerai
   opencode debug agents
   ```
   Должны быть 4 агента `1c-*` (`1c-architect`, `1c-scout`, `1c-coder`, `1c-tester`) и две модели RouterAI.
6. Создать ярлык на рабочем столе:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File C:\Users\<имя>\.config\opencode\scripts\create-shortcut.ps1
   ```
7. Запустить ярлык **1С-архитектор**: при первом запуске спросит путь к проекту, сама развернёт `project/` и откроет OpenCode. В нём - `Tab` -> `1c-architect`.

Подробный порядок для человека без программирования - `1C-АГЕНТ-ИНСТРУКЦИЯ.md`.

## Вставить в свой opencode.json

Готовый фрагмент - `opencode.example.json`: провайдер `routerai` (две модели) и четыре агента. Вставьте в свой конфиг, не заменяя остальные секции. Если удобнее - скриптом:

```powershell
node C:\Users\<имя>\.config\opencode\scripts\add-mcp.cjs gyrfalcon -- "%LOCALAPPDATA%\1c-mcp-tools\gyrfalcon.exe" serve --db .opencode\1c-index.db --profile all
```

Скрипт добавляет MCP в секцию `mcp`, проверяя JSON и не теряя остальные записи.

| MCP | Что даёт | Установка |
|---|---|---|

| `1C Testpilot` | клики в живом интерфейсе 1С | `.epf` из релиза |

Полный список с репозиториями и командами - `skills/1c-mcp-catalog.md`.

## Затраты

```powershell
node scripts\cost-report.cjs                # всё время
node scripts\cost-report.cjs --today        # сегодня
node scripts\cost-report.cjs --session <id> # одна сессия
node scripts\cost-report.cjs --md           # таблица markdown
```

Цены RouterAI - в `scripts/prices.routerai.json` (за 1 млн токенов, в рублях). Для моделей других провайдеров без прайса берётся их собственная оценка стоимости × курс из файла.

## Безопасность

- Ключи только в `.env`, `.env` в `.gitignore`.
- В репозитории нет ключей, баз и персональных данных - проверено поиском.
- Пути (`~/.config/opencode`) зашиты под Windows - правьте, если ставите на Linux/macOS.
- Агент не пишет в рабочую базу без явного разрешения, не делает `git push`/`reset --hard` без вопроса.
