## Unity MCP (Model Context Protocol)

**Файл:** `mcp.json`

| Сервер | Назначение | Команда |
|---------|------------|---------|
| **unity** | Unity Editor + C# скрипты | `@nurture-tech/unity-mcp-runner` |

**Настройка:**
```json
"unity": {
  "command": "npx",
  "args": [
    "-y",
    "@nurture-tech/unity-mcp-runner",
    "-unityPath", "C:/Program Files/Unity/Hub/Editor/6000.0.0f1/Editor/Unity.exe",
    "-projectPath", "D:/Project/lokallP/НазваниеВашегоПроекта"
  ]
}
```

**Что умеет:**
- Чтение/создание C# скриптов
- Манипуляция сценами Unity
- Настройка компонентов
- Запуск/остановка Play Mode
- Доступ к ассетам проекта

**Пример запроса:**
```
"Создай скрипт PlayerController.cs в Unity проекте"
"Добавь Rigidbody к объекту Player"
"Запусти Play Mode в Unity"
```

## MCP Серверы (Model Context Protocol)

**Файлы:** `mcp.json`, `opencode.json`

| Сервер | Назначение | Команда/Тип |
|---------|------------|----------------|
| **godot** | Godot Engine 4.x (запуск проекта, сцены, ноды, GDScript, debug output) | `npx @coding-solo/godot-mcp` |
| **blender** | Blender 3D (сцены, моделирование через аддон) | `uvx blender-mcp` |
| **playwright** | Браузер: навигация, клики, скриншоты, accessibility snapshot | `npx @playwright/mcp` |
| **zai-mcp-server** | Зрение агента: анализ изображений/скриншотов/видео, UI-to-code | `npx @z_ai/mcp-server` |
| **filesystem** | Доступ к файлам | `@modelcontextprotocol/server-filesystem` |
| **ddg-search** | Поиск DuckDuckGo | `duckduckgo-mcp-server` |
| **fetch** | Загрузка URL | `mcp-server-fetch` |
| **blender** | Blender 3D | `blender-mcp` |
| **context7** | Документация библиотек (remote) | `https://mcp.context7.com/mcp` |

**Настройка локальных серверов:**
1. Файл `mcp.json` в корне opencode
2. Используется `npx` или `uvx` для запуска серверов
3. Аналогично LM Studio (Ctrl+2 → mcp.json)

**Настройка remote серверов (Context7):**
```json
"mcp": {
  "context7": {
    "type": "remote",
    "url": "https://mcp.context7.com/mcp",
    "headers": {
      "CONTEXT7_API_KEY": "{env:CONTEXT7_API_KEY}"
    }
  }
}
```

**Переменные среды (.env):**
- `CONTEXT7_API_KEY` — ключ от context7.com
- `OPENROUTER_API_KEY` — ключ OpenRouter
- `AIHUBMIX_API_KEY` — ключ AIHubMix

**Источники:**
- LM Studio MCP: https://youtu.be/WqzYvCZ5WWE
- Context7: https://context7.com

→ `skills/1c-mcp-catalog.md` -> [Untru/1c-mcp](https://github.com/Untru/1c-mcp) -> свой навык; установка - `node scripts\add-mcp.cjs <имя> -- <команда>`

→ `skills/1c-project-workdir.md`, шаблон `templates/1c-project/`, скрипт `powershell -File scripts/init-1c-project.ps1 -ProjectPath "<проект>"`
